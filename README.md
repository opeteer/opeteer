### About Me

Software and Cloud-Native Engineer focused on designing robust, distributed, and scalable architectures. Experienced in building cloud infrastructure, container orchestration, network automation, high-performance backends, and full-stack platforms.

* **Currently Building**: Ad-hoc disaster relief energy & communication systems for **FIT COMPETITION 2026** ([`PANDORA`](https://github.com/opeteer/PANDORA)).
* **Systems & Concurrency**: Engineering cloud storage engines ([`hornetzDrive`](https://github.com/opeteer/hornetzDrive)) and modular frameworks ([`ztatic-go-framework`](https://github.com/opeteer/ztatic-go-framework)) in **Golang**.
* **Cloud & Infrastructure**: Architecting Kubernetes clusters ([`infra-for-kube`](https://github.com/opeteer/infra-for-kube)), GitOps IDP pipelines, and network automation with **Tailscale & Docker**.
* **Server & Network Engineering**: Implementing hybrid virtualization environments with **Vagrant, Docker Compose, and FRP reverse tunneling** ([`zomboid-server`](https://github.com/opeteer/zomboid-server)).
* **Full-Stack Ecosystems**: Developing end-to-end multi-tier web platforms ([`LeaDrive`](https://github.com/opeteer/LeaDrive)).
